# 九个数据集的统一五折与缺失掩码

[完整协议及使用示例](说明.md) · [划分数量](划分数量.csv) · [实际缺失率](实际缺失率.csv)

本目录收录2026-10-26已生成的固定划分：9个数据集、45套五折索引、180个视图掩码和225个标签掩码。基础种子为20261026。2026-10-28归档上传时未重新生成划分、读取原始数据或重新运行哈希核验；核验结果.json保留的是原生成批次的记录。

- 需要验证集的方法使用约64%训练、16%验证、20%测试，选好模型后直接测试，不强制合并重训。
- 不需要验证集的方法使用outer_train_idx中的约80%训练，与上述方法共用同一test_idx。
- 索引为原始MAT样本行号，从0开始；使用前必须对应相同数据版本和样本顺序。
- 视图缺失率：0%、10%、30%、50%；训练标签缺失率：0%、10%、30%、50%、70%。主设置为50%视图缺失、50%标签缺失。所有方法共用同折、同缺失率的掩码。
- unknown标签通过known_mask隔离，不能作为负标签；详细训练、验证、测试接口见完整协议。

上表数据目录只用于查找；同名数据可能有多个版本，准确的原始文件身份、样本顺序、视图维度及标签列数以各划分目录的metadata.json和sources.json为准。IAPRTC12是4999样本的五视图本地子集，不能套用到其他同名版本。

protocol_io.py用于加载固定索引与掩码。prepare_fivefold.py是原五折生成脚本，prepare_masks.py是原掩码生成脚本；日常实验直接读取现成文件即可。若需从原始数据重新生成，先将sources.json中的历史本机绝对路径改为当前机器对应路径，并输出到新目录。原始MANIFEST.json及核验记录只涵盖原生成批次，不涵盖本README和补入的五折生成脚本。
