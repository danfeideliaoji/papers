# 许可判定与证据说明

核验日期：2026-10-25。

1. 先按仓库清单定位正文，读取页数与 SHA-256；不会把代码许可证套用于论文。
2. 从 PDF 提取版权/许可提示，仅作线索。例如 P137 中的 CC BY 4.0 指 UCI 数据集，不覆盖论文；P126/P145 的 Creative Commons 文字是数据来源说明，不能当成论文许可。
3. PMLR 正式出版论文采用 [PMLR 出版协议](https://proceedings.mlr.press/pmlr-license-agreement.html) 第 2 条的 CC BY 4.0，第 3 条要求引用原出版物并链接论文页。本轮找到的 19 个官方论文页与其 PDF 均已核对题名；17 份与仓库副本 SHA-256 相同，2 份版本不同。完整 URL、网页哈希、PDF 哈希与核查时间记录在 `official_version_checks.json`。论文网页并未直接链接到该协议，记录中的 `license_agreement_linked_from_article=false` 是准确的网页结构事实，许可依据是出版方的公开协议，不是网页页脚版权字样。
4. P131 的文章专属权利声明与本地 PDF 第 23 页均为 CC BY 4.0。P123/P141/P149/P175 的本地 PDF 明确写明 CC BY-NC-ND 4.0，不能据此公开翻译；本轮未请求或取得这些论文的额外授权。
5. [AAAI 官方规则](https://ojs.aaai.org/index.php/AAAI/about) 说明再出版需许可；本轮没有发现适用于相关仓库副本的单独改编再分发授权。其他未核实论文逐篇标为待确认，不以会议名称直接推定论文可改编。
6. 许可允许改编后，仍要逐图检查第三方例外。只有 RCSC 已完成该步并公开中文全文；其余候选尚未进入全文发布。

RCSC 的额外 OpenReview 元数据读取曾遇到网页验证页，官方公共 API `https://api2.openreview.net/notes?id=9uBY2PBfcf` 返回 HTTP 403；没有重试或绕过。这项可选核查未获得结果，RCSC 许可依据仍为此前已核实的 PMLR 出版协议和逐字节一致的正式出版 PDF。

上述是本批工作记录，未宣称已取得所有论文的作者授权，也未把仓库所有者身份视为论文著作权归属证明。权限待确认、缺原文、版本不同和图片未审分别记录，继续推进其他许可明确的条目。
