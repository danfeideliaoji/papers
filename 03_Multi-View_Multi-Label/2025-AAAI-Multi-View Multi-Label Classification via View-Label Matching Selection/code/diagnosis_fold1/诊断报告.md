# 第一折预测塌缩的原因

结论：在这一固定折上，沿用旧学习率 0.01 是预测塌缩的主要触发因素。改为 0.001 的单因素对照恢复了有区分度的预测。这是训练稳定性诊断，不是五折成绩或论文复现成功的证据。

## 直接证据

训练集六个标签的频率约为 0.296、0.280、0.443、0.253、0.285、0.319。用当前频率加权损失计算，不区分样本、不区分标签的最优公共常数是 0.396746。坏模型的验证预测均值约为 0.398，各标签跨样本标准差只有 0.00043～0.00065。它确实接近公共常数解，而不是单纯的打印或指标计算错误。

前几轮验证集预测曾在全负与全正之间摆动：第 2 轮两个 F1 为 0，第 3 轮的 Hamming loss 为 0.673684，对应全正预测，第 4 轮又回到全负。最终验证最佳轮为第 33 轮。

分类梯度路径存在，但训练后梯度非常弱。例如输入视图 1 的分类梯度范数从初始化的 2.613 降到 0.001475；第二层节点模块的分类梯度仍存在。初始化时边解码 logits 的跨标签 RMS 标准差约 0.463，坏模型降到 0.001422。中间层也逐渐失去样本和标签差异。

## 最小单因素对照

两组使用相同模型源码快照、种子 2020、五折中的第一折、379 个训练样本、95 个验证样本、β=1、阈值 0.5、SGD 动量 0.9、weight_decay=0.005、显式范数正则系数 0.005、衰减系数 0.933。对照只将初始学习率改为 0.001，固定运行 33 轮，没有网格搜索或追加其他折。

| 33 轮内验证集选模结果 | 学习率 0.01 | 学习率 0.001 |
| --- | ---: | ---: |
| 最佳轮 | 33 | 32 |
| LRAP | 0.627281 | 0.855556 |
| Micro-F1 | 0 | 0.711864 |
| Macro-F1 | 0 | 0.700051 |
| Hamming loss | 0.326316 | 0.178947 |

0.001 组最佳轮的验证预测范围为 0.01145～0.96615，跨样本 RMS 标准差约为 0.3277；阈值 0.5 下有 168 个正预测。分类训练损失约 0.296，而显式正则仍约 4.980。保存模型重新加载后，所有验证指标重放一致。

这也说明不能只因为正则的数值大于分类损失，就把它认定为塌缩的主要原因：对照保留了原来的两种正则，却恢复了学习。坏模型后期的正则梯度确实超过很多模块的分类梯度，但这一观察本身不能确定塌缩的初始原因。

## 为什么不能机械沿用旧学习率

修改中启用了可训练输入/标签投影、调整了节点—边传播顺序，并更换损失权重。只比较同一个初始模型和同一个训练批次，旧 0.8/0.2 损失的梯度范数为 5.7506，论文频率权重损失为 12.8329，增大约 2.23 倍。这个局部测量显示优化尺度已经改变；直接保留 0.01 和 0.9 动量，没有充分检查训练稳定性。
