# Emotions 公式对齐版：五折划分中的第一折实验结果

已完成第一折 80 轮 GPU 训练，按验证集 LRAP 选择第 33 轮模型。验证集最佳 LRAP 为 0.859240。训练/保存用时 78.61 秒（约 1 分 19 秒），不含解释器启动与后续核验。

这是单折结果，未执行其他四折，也未计算跨折标准差。训练 379 行、验证 95 行、测试 119 行；划分与上一版完整相同。

| 指标 | 上一版第一折 | 本次第一折 | 论文五折汇总 |
| --- | ---: | ---: | ---: |
| AP / LRAP ↑ | 0.784407 | 0.784337 | 0.826 ± 0.012 |
| Micro-F1 ↑ | 0.681818 | 0.682609 | 0.692 ± 0.015 |
| Macro-F1 ↑ | 0.674016 | 0.664146 | 0.679 ± 0.017 |
| Hamming loss ↓ | 0.196078 | 0.204482 | 0.193 ± 0.019 |
| Ranking loss ↓ | 0.177288 | 0.174977 | 0.144 ± 0.013 |
| Coverage ↓ | 1.714286 | 1.697479 | 1.659 ± 0.055 |

本次 LRAP 比上一版低约 0.000070（0.007 个百分点），基本一致。Micro-F1 高 0.079 个百分点，Macro-F1 低 0.987 个百分点，Hamming loss 高 0.840 个百分点；Ranking loss 与 Coverage 略有改善。本折没有显示整体性能提升。

与论文相比，LRAP 低约 4.17 个百分点，Micro-F1 低 0.94 个百分点，Macro-F1 低 1.49 个百分点；Ranking loss 高 3.10 个百分点。论文为五折均值，本次为单折，不能据此判断统计显著性或完整复现成功。

## 固定配置与解释边界

- RTX 4060 Laptop GPU，CUDA；种子 2020，k=5，β=1，阈值 0.5，初始学习率 0.001。
- 三层卷积、分离的视图/邻居/标签聚合、共享的无向边状态、两阶段 rho/phi 边更新。
- SGD 动量 0.9，指数学习率衰减 0.933；weight decay 和显式范数正则都为 0。
- 模型各处修改是一次公式对齐版本更新，不是单因素消融，因此不能把得分变化归因于某一项。
- β、精确 MLP 结构、邻居更新及 KNN 空间仍存在论文未明确的实现选择，详见 ../formula_alignment/公式对齐报告.md。
- 原版与上一修正版结果、源码和检查点保留；本次未调阈值、追加种子、追加折或做参数搜索。

## 核验

源码与训练接线验证的冻结快照哈希一致；数据哈希、精确划分、训练集拟合归一化与标签频率、验证选轮均核验通过。保存模型重新预测后，标签排序、阈值分类和六项测试指标一致。

最初 1e-6 概率容差下，有一个值出现约 1.88e-6 偏差。连续 GPU 重放也有约 1.31e-6 波动，CPU 与保存预测最大偏差约 3.01e-6。v3 核验采用 atol=5e-6、rtol=1e-6，同时要求标签排序及阈值分类完全一致，指标逐项核对。本次最终重放最大概率差 1.46e-06；不是逐位数值完全相同。详细证据保存在 replay_numerics.json 和 verification.json。
