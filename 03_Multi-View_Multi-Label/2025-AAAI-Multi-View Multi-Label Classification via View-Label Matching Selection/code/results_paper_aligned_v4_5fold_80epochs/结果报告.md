## 固定配置

- CUDA，Emotions 593 行、两个视图、六个标签；五折随机种子 2020，各折模型种子为 2020 至 2024。
- 三层卷积、k=5、β=1、学习率 0.001、SGD 动量 0.9、指数衰减 0.933、阈值 0.5，两项额外正则均为 0。
- 每折外层训练部分再留出 95 行验证集；实际训练为 379 或 380 行，外层测试为 119 或 118 行。
- 归一化、频率和邻居库仅用内层训练数据；按验证 LRAP 选轮，训练结束后计算该折最终测试成绩。
- 视图/邻居消息分别聚合，角色排序的双向图内消息避免任意标签编号依赖；匹配边得分仍按视图平均。
- dropout 参数仍没有对应的 Dropout 层，训练顺序固定。此次保持其行为以完成固定版本实验，不追加调参、阈值搜索或重跑选最高分。
