## 明确差异及修改

| 论文依据 | 前一轮修正版/工作文件 | 当前实现 |
| --- | --- | --- |
| 式 (4)，其他视图与 KNN 邻居用不同 rho，分别除以 V-1 和 K | 共用一个网络，混合求均值；更新器只拼接三路 | 两个独立消息 MLP，分别求均值；自身、其他视图、邻居、标签共四路拼接 |
| 式 (4)，标签到视图通道未写 1/Q | 对 Q 个标签求均值 | 按公式字面求和，明确记录该解释 |
| 式 (1)、(4)，视图节点读取 V-1 个其他视图 | 视图编号链加自环，超过两视图时不全连接 | 完全视图图，无自环，支持不同视图数 |
| 图是无向的，式 (7)-(9) 每条边有一个状态 | 视图和标签的两个方向拥有分离状态 | 一条无向边存一份属性，节点两端消息共用该属性；匹配边双向读取同一状态 |
| 式 (7)-(9)，rho(端点) 后接 phi(旧边,rho)；论文称所有 rho/phi 为 MLP | 一个 MLP 同时处理端点与旧边 | 各类边设独立 rho、phi 两个 MLP；跨视图边与邻居边按式 (7) 共享对应 rho/phi |
| Algorithm 1，先节点后边；循环次数 C | 快照为两层；漂移的工作文件还保留无用模块 | 按先节点后边执行，可配置 C；默认 3，依据是 Scene 上 C=3 最好，并非已证明各数据集统一用 3 |
| 式 (11)，仅加权交叉熵 | 同时加 0.005 显式参数范数与 0.005 weight decay | 两项正则默认 0，可显式配置，不把额外正则混称为论文目标 |

## 实现与来源保护

新模型在 `paper_gn.py`，构图在 `paper_graph.py`；`strict_training.py` 直接导入新模块。`GNBlock_model.py`、`build_graph.py` 为兼容导入入口。这样旧文件再次漂移时不会改变新训练主体。旧工作文件归档在 `pre_change/`，上一轮完整实验的 source/、检查点和预测没有修改。

图构造采用向量化索引，直接在输入设备执行；邻居特征保持梯度，避免逐节点 CPU/GPU 拷贝。批次和尾批按实际尺寸计算。

`source/` 保存本次接线短跑使用的源码，`source_manifest.json` 保存源码、数据、论文哈希。今后完整运行也保存新模型模块和构图模块。

## 核验范围

`verify_paper_alignment.py` 对 1/2/3 个视图、1/3 个批次样本，以独立邻接遍历核对节点聚合；同时检查边 rho/phi、全连接无自环、邻居属性与索引、标签占位不影响输出、尾批与逐样本输出一致、分类梯度和一次优化步骤。旧实现先在独立邻居网络断言处失败。

CPU/GPU 检查结果见 `verification_cpu.json` 和 `verification_cuda.json`。最后一层节点模块需要非零分类梯度；最后一层图内边的 32 个 rho/phi 参数张量无分类梯度，是式 (10) 仅解码匹配边且没有后续节点读取的自然终点，不以正则梯度冒充任务梯度。

`verify_paper_training.py` 使用上一轮固定五折划分中的第一折，只有 379 行训练和 95 行验证。一轮训练覆盖 6 批，包括尾批，检查有限损失/梯度、验证前向与内存中的保存/载入重放。结果见 `dev_smoke.json`；测试评估次数必须为 0。该短跑不用于论文分数比较。

## 仍无法从论文唯一确定的事项

- β 的具体数值未给出，默认 1；不按测试结果调参。
- 各 MLP 的宽度、激活、归一化、初始化未完整给出，沿用作者代码的 128/256 维、ReLU 和 LayerNorm 等结构选择。输入/标签的可学习投影及边初始化编码亦属于维度适配选择，并非论文提供了其精确架构。
- rho 符号把“逐消息 MLP”和“收集多个消息”合写，式 (4) 的标签通道缺少显式求和符号及 1/Q。当前采用逐消息 MLP 后求和的字面解释；不能声称排除了作者其他解释。
- KNN 的距离、在原始特征还是投影特征计算、是否重建未明确；当前保留余弦距离、当前投影空间、每轮重建，且只用训练库。
- 邻居辅助节点没有独立更新公式。当前仅更新原样本的 V 个视图节点，辅助邻居保持当前输入投影，邻居边正常更新；不添加未写出的节点更新规则。
- 无向边的拼接顺序仍须约定。当前视图/标签按局部编号固定顺序，邻居边按邻居与中心拼接；共享边状态不代表已经证明节点重编号等变性。
- 论文的损失式缺少负号，代码最小化负对数似然；使用元素均值控制尺度，而非印出的总和。这影响优化步长尺度，已明确记录。
- 优化器、学习率计划和原始五折具体索引不完整公开；当前保留 SGD 动量 0.9、学习率 0.001、衰减 0.933、种子 2020。训练/dev/test 协议比论文简述更明确，pc 只由训练标签估计。

因此可以称为“已修正明确公式差异，并通过结构/运行核验”，尚不能称严格完整复现，也没有本次新模型的完整测试成绩。上一轮 LRAP 0.7844 属于上一版本，不能转记为本次模型成绩。
