# VAMS 六项修正

| 问题 | 修正后的行为 |
| --- | --- |
| 测试折选模 | 默认五个外层折，外层训练部分留出 20% 验证集；按验证 LRAP 选轮，最后测试一次。 |
| 全数据归一化 | Min-Max 只在内层训练行拟合，验证/测试沿用其统计量。 |
| 冻结随机投影 | 输入 MLP 参与分类训练并保存；每轮按当前表示重建 KNN。 |
| 标签编号链 | 完全标签图，按式 (5) 连接 Q-1 个其他标签，不含自环。 |
| 固定损失权重 | 式 (11)：正样本 exp(β(1-pc))，负样本 exp(βpc)，pc 仅由训练标签计算。 |
| 最后节点不参与分类 | 算法 1 先节点后边；最后节点通过匹配边更新进入解码，不增加分类器。 |

分折不再丢弃余数，593 个样本均进入一次外层测试。验证/测试 KNN 只查询内层训练库。训练邻居按真实行号排除自己，也适用于重复特征。

## 运行

在 code 目录打开 PowerShell：

    .\run-windows.ps1
    .\run-windows.ps1 -Epochs 80 -Folds 5 -Beta 1.0

保留五折划分，只执行第一折的完整 80 轮：

    .\run-windows.ps1 -Epochs 80 -Folds 5 -FoldIndex 1

FoldIndex 从 1 开始编号；单折输出明确记录 outer_folds=5、selected_folds=[1]，不计算跨折标准差，也不称为五折平均结果。

第一条是两折、每折两轮 GPU 短跑，第二条是五折、每折 80 轮。每次保存到独立的 results_corrected_日期时间 目录，也可用 -OutputDirectory 指定空目录。终端显示进度，不保存文本日志。修正版从头训练，不加载旧模型。

默认 CUDA 环境为 D:\python-venv\cuda\.venv\Scripts\python.exe。关键逻辑包含中文注释，demo.py 与 train.py 使用相同训练流程。

验证命令：

    & 'D:\python-venv\cuda\.venv\Scripts\python.exe' verify_corrections.py --device cuda
    & 'D:\python-venv\cuda\.venv\Scripts\python.exe' verify_corrected_run.py results_corrected_smoke --device cuda

## 已验证与限制

第一折 80 轮运行出现常数预测，已通过固定划分的单因素对照定位：旧学习率 0.01 不适配修正版，默认改为 0.001。33 轮内最佳验证 LRAP 为 0.855556、Micro-F1 为 0.711864，保存模型重放一致；这些是验证集诊断结果，不是新的测试成绩。详细见 [诊断报告](diagnosis_fold1/诊断报告.md)。Windows 脚本可用 -LearningRate 指定学习率。

Emotions 两折 × 两轮 GPU 短跑已完成，覆盖全部 593 个测试行。模型重放、验证选模和训练预处理检查通过。短跑 LRAP 约 0.539807，仅验证跑通，不用于论文效果比较。尚未重跑五折 × 80 轮。

只用分类损失、不加正则反传：第二层节点模块 48 个实际参数张量全部有非零分类梯度。原来未使用的 40 个编码器参数已删除。最后一层图内边更新有 16 个参数张量没有分类梯度：传播终点没有后续节点读取，匹配边解码也不读取这些图内边。对此单独记录，不以正则梯度冒充分类梯度。

论文未给出 β 的具体取值，默认 1.0，可配置。pc 为避免泄漏仅用内层训练标签计算。论文印出的损失缺少负号，代码最小化负对数似然，并取元素均值。保留原实现两层传播、视图得分平均、优化器和正则参数，不自动调参。

这次修正不代表所有细节已逐式复现。原实现仍将视图消息和邻居消息合并聚合，而论文式 (4) 分开描述；论文层数和 β 的实验配置也未完全确定。因此不宣称完整严格论文复现或性能提升。

## 历史结果

Model_Best_GPU/ 和 results/ 保留旧六折模型与结果，其分数只作旧协议记录。results/source/ 保持原样，verify_full_run.py 加载该快照重放旧模型。新结果目录保存分割索引、逐轮验证指标、最终测试指标、模型、预测、预处理统计量、源码快照和校验记录。旧最高分不能作为修正版的公平对照。
