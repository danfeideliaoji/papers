- 数据和全部五折划分与 v3 完全相同；训练 379、验证 95、测试 119 行。
- 训练参数与 v3 相同：种子 2020、三层卷积、k=5、β=1、学习率 0.001、SGD 动量 0.9、指数衰减 0.933、阈值 0.5、两项额外正则均为 0。

- 源码哈希、数据、分折、训练集拟合归一化和频率、验证选模及保存模型的 dev/test 重放均通过。
- GPU 重放最大概率误差 1.43e-06；采用 atol=5e-6、rtol=1e-6，标签排序、阈值判断及六项指标一致。
