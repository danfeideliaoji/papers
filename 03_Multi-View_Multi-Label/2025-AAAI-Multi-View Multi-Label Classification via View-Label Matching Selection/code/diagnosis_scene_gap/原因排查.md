# Scene 复现差距排查（2026-10-01）

结论：当前证据不足以判断论文数据造假。发现本地 CUDA 从头训练不可精确重复这一明确问题；论文和代码也存在可复现性及报告一致性问题。尚未量化任何单一因素能解释全部 3.72 个百分点的测试 LRAP 差距。本轮不产生新测试成绩，不替换原五折结果。

## 已确认：同一初始状态的 CUDA 训练轨迹不稳定

以 Scene 第一折的同一训练/验证划分、相同种子、相同初始权重、相同固定批次重复第一轮训练。四次模型初始状态 SHA-256 完全相同：ad60f0452f83560956d8136c05bf81259ada1ad122467ec35f6450bb612ec826。

| 配置 | 第一次验证 LRAP | 第二次验证 LRAP | 两次验证概率最大差异 |
| --- | ---: | ---: | ---: |
| 普通 CUDA | 0.429495 | 0.425988 | 0.116719 |
| 确定性 CUDA | 0.431840 | 0.431840 | 0 |

普通 CUDA 第一批损失只有约 1.2e-7 的变化，但后续优化产生明显分歧。这证明模型训练会放大小的数值差异；只固定随机种子和 cudnn.deterministic 不足以保证本训练路径可重复。确定性对照使用 CUBLAS_WORKSPACE_CONFIG=:4096:8 和 torch.use_deterministic_algorithms(True)，其余设置相同；同一进程内两次重启模型的一轮检查通过，不等于完成了跨进程、80 轮或跨设备的确定性验证。

当前聚合使用 CUDA index_add，属于需要检查的并行归约路径；本轮没有通过逐模块干预定位唯一算子，不能断言全部差异只来自 index_add。确定性计算恢复重复性，也不保证提高最终分数。

此前完整五折的保存模型重放仍成立（最大概率误差约 4.23e-6，指标相同）。但“训练好的模型能重放”和“同一随机种子从头训练能得到同一模型”是不同检查。此前没有覆盖后者；不能据前者声称完全训练复现。

证据：numerics_standard.json、numerics_deterministic.json；脚本 probe_scene_numerics.py 的冻结副本保存于 diagnostic_source/。

## 已确认的评估条件差异

保存的旧代码在 results/source/util.py:620 附近用测试折特征拟合测试邻居库；当前 source/strict_training.py:117 的预测邻居库来自内层训练数据。这是利用同批测试特征的转导条件与归纳条件的差异，不等于测试标签直接进入模型。

旧代码 results/source/util.py:725 调用 testa 获得每轮测试指标，:755 按测试 LRAP 选最佳模型，并将选中轮次的指标汇总。这样的最高分不能当作独立测试评估；但不能仅凭该代码证明论文表格一定由这一流程产生。

当前 Scene 每折内层训练 1540 行；只做外层五折则有 1925/1926 行训练数据。内部验证使训练数据减少约 20%，论文没有描述是否采用同样的内部划分。严格归纳实验与论文不明的训练/选模条件不能视为完全同一协议。

验证集特征库替换诊断：冻结全部模型，仅把验证预测的邻居库从训练集换为验证集自身，排除自身行号。五折平均 LRAP 变化为 -0.001503，即 -0.15 个百分点。因此本次检查不支持“只改变邻居库就能追回论文差距”。这不是复刻旧代码的完整转导训练协议，也不是测试集效果证明。

## 优化与泛化：有线索，尚未建立因果归因

最佳模型在排除训练自身邻居后，五折训练 LRAP 平均 0.875833，验证 LRAP 平均 0.839953。第三折训练/验证分别为 0.927522 / 0.841364，存在明显泛化差距；第五折为 0.837121 / 0.824266，训练本身也偏低。不能把所有折统一归因于过拟合或欠拟合。

五折验证 LRAP 从第 60 至第 80 轮分别提升约 2.14、2.11、0.41、1.53、2.79 个百分点。第一、第五折选中第 80 轮，80 轮充分收敛尚未证实。学习率从 0.001 降至第 80 轮约 4.17e-6，优化进度值得检查。

预先固定的单因素诊断只跑第一折 80 轮，将衰减 gamma 从 0.933 改为 0.99，其余模型、种子、划分和顺序固定；只看训练和验证，不计算测试成绩。最佳验证 LRAP 为 0.856753，历史基线为 0.865195，没有观察到改善。但诊断中发现普通 CUDA 训练不可精确重复，因此这两条轨迹不能当作严密配对的 gamma 因果对照，也不能断言衰减无影响。本轮不继续搜索 gamma、学习率或训练轮数。

在 0.10 至 0.90、步长 0.05 的阈值网格上描述性检查验证 Micro-F1，五折平均最大改善只有 0.004401（0.44 个百分点）；不能解释全部分类分数差距，且阈值不改变 LRAP。未将选择的阈值用于新测试。

证据：checkpoint_probes.json、schedule_plan.json、schedule_epoch_metrics.csv、schedule_result.json。模型源码和数据哈希核对通过。

## 论文中的真实异常及其边界

直接重读 paper.pdf，第 5 页 Table 1 和第 7 页 Table 3，确认：

- Scene VAMS Coverage 标准差分别为 0.058 与 0.008。
- Corel5k VAMS Hamming 均值分别为 0.012 与 0.013。
- Table 1 严格比较均值，VAMS 对 LrMMC 为 35/42 胜，约 83.3%；正文为 85%。Scene Micro-F1 的 VAMS 0.748 低于 LrMMC 0.772，正文笼统的“比第二名提升”表述不适用于所有数据集。

还有更明确的条件性数值矛盾：对于 6 个标签、每行至少一个正标签，采用常规未归一化 Coverage（coverage_error-1）及成对 Ranking Loss 时，必有均值 Coverage ≥ 5 × 均值 Ranking Loss。Scene 官方数据和本地 Emotions 都没有空标签行。

| Table 1 中 SIMM | Ranking Loss | 未归一化 Coverage 的下界 | 论文 Coverage |
| --- | ---: | ---: | ---: |
| Scene | 0.280 | 1.400 | 0.248 |
| Emotions | 0.344 | 1.720 | 0.457 |

推导：每行有 p 个正标签，最差正标签排名减一为 C。所有正标签与负标签的错序对数不超过 p(C-p+1)，因此 RL ≤ (C-p+1)/(Q-p) ≤ C/(Q-1)。全正标签的 RL 为零。对各样本求均值仍成立。63 种非空标签位置组合的穷举检查通过；采用相同的最差并列排名定义时，并列分数也满足该边界。

这两行在同一未归一化定义下不能同时成立；若 SIMM Coverage 除过标签数，则可能解释这些数字。因此这是指标口径、录入或来源一致性问题的证据，不能直接判定生成了虚假实验数据。此矛盾位于基线列，并没有证明 VAMS 自身成绩违反该约束。

论文式 (11) 印出的损失缺少负号，β、精确 MLP、KNN 空间/刷新、优化配置和内部验证协议未充分说明。多项实现选择存在不确定性。正式结果仍来自我们修正后的 v4，而非作者代码逐字执行；成绩偏低也可能来自这些实现或协议选择。

证据：paper_table_checks.json（原论文哈希、表格逐项均值、计数、约束及检查结果）。

## 当前判断与优先级

可以说：公开材料不足以支持严格可复现性；旧代码有测试选模问题；论文存在内部表格不一致及条件性指标矛盾；本地训练有明确的数值重复性问题。

不能说：已经证明作者伪造数据、伪造训练日志或凭空编造 VAMS 成绩。未取得作者原始分折、预测、模型和日志，也未证明其表格由旧代码中的不安全流程生成。
