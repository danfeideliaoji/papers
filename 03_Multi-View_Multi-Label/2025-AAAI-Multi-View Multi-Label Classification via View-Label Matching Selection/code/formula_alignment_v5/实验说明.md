# Scene v5：确定性训练与有限优化

本轮目标是在修复训练不可重复后，尽量接近论文 Table 1 的 Scene 效果。现有 v4 五折模型和结果保留；v5 没有更改模型公式、图结构、输入投影、损失或视图划分。

已修复：首次 CUDA 矩阵运算前配置 CUBLAS_WORKSPACE_CONFIG=:4096:8，seed_all 开启 torch.use_deterministic_algorithms(True)，同时固定 cudnn 设置。不允许无法确定性执行的算子静默退回普通计算。两个独立进程各训练真实 Scene 第一折三轮，最终权重、每批损失、验证预测完全相同；不声称已经重复完整 120 轮。

固定实验方案：

- Scene 2407 行，沿用 v4 五折和内层 20% 验证划分，种子 2020 至 2024。
- 每折独立比较 SGD（动量 0.9）和 Adam，从该折相同初始权重开始；不依据第一折分数向其他折传递配置。
- 两者学习率均为 0.001，指数衰减 gamma=0.933，β=1，额外正则为零，批量 64，隐藏维度 128，C=3、k=5，分类阈值固定 0.5。
- 每候选至少训练 80 轮、最多 120 轮；达到 80 轮后，连续 20 轮没有更高验证 LRAP 则结束该候选。
- 每折按内层验证 LRAP 同时选择优化器和轮次，随后只对选中模型计算该折最终测试成绩。
- 两个候选、五折最多共 1200 轮；完成后不根据测试成绩添加配置、种子或阈值搜索。

有限搜索是训练优化尝试，不是新的模型创新。论文未给明确优化器细节，使用 Adam 不能作为作者采用同一优化器的证据。此数据集的旧五折成绩已经见过，因此最终结果属于探索后同数据评估，不能包装成完全独立确认。

运行使用 source/ 冻结版本，并核对 source_manifest.json；新结果位于 results_scene_v5_deterministic_search/，包含所有候选验证曲线、最佳模型、选中模型、分折和预测。重放使用 verify_deterministic_search.py；旧 v4 结果仍必须从其各自 source/ 重放。
