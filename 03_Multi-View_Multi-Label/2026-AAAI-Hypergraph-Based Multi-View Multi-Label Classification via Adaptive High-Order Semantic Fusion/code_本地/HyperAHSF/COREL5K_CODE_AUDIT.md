## 已核实的数据

原始 `Multi_View_dataset/corel5k.mat` 为 4999 样本、260 个二值标签、6 视图，维数 `[100,1000,512,4096,4096,4096]`。共有 16979 个正标签，7 个全零标签样本。旧缓存确实对应 `RandomState(3407)` 的五折，外层折大小 `[1000,1000,1000,1000,999]`，训练/留出 ID 互斥，标签与原始数据对应。

旧 fold0 六个视图的留出特征与“先在全部 4999 样本拟合 StandardScaler，再切分”的结果逐元素相同，最大差均为 0。这是原预处理已存在的泄漏，不能仅归因于 Gemini 新修改。修正入口绕过旧缓存，保留原始样本和相同五折 ID，每折在训练部分 fit，再 transform 训练和留出部分。

全零标签样本不删除。AP 按原代码/sklearn 约定计为 1；Coverage 延续 sklearn coverage_error 减 1 的定义。论文对这些边界情况没有给出足够细节，不能默认与论文的数据版本/指标处理完全相同。

## 确认的问题与修复

| 问题 | 证据 | 修复 |
|---|---|---|
| 外层标签用于选轮次 | 原 train.py 取五折平均 AP/Micro-F1 的最优 epoch；旧 eval_5folds.py 每折分别选最优 | 训练过程中不访问留出指标；固定配置的末轮一次评价 |
| 外层折用于选配置 | tmp 下七个调参脚本在 fold0 扫网络层数、学习率、权重衰减、k、alpha、阈值 | 保留历史，配置标明 Gemini 本地调参适配，不作独立测试或作者参数宣称 |
| PReLU 跨折继承 | HyperGNN 的模块默认参数是同一个可训练对象；修改模型 A 的参数影响新模型 B | 每个 HGMVMLC_Model 新建激活对象，保留同一模型内部共享，禁止不同折共享 |
| 向量化损失除零 | 全标签相同导致 N-group_size=0，出现 NaN/Inf；旧循环原有无负样本保护 | 无负样本时负项置零，分母使用安全值；保留梯度 |
| 损失 dtype 错误 | float64 输入与固定 float32 累加缓冲冲突 | 缓冲跟随输入 dtype/device；普通组的数值和梯度与旧循环对照 |
| 评估图缓存失效 | 换一个留出数据集仍使用第一张图，样本数减少时直接越界 | 特征对象/修改版本/形状及构图参数变化时重建缓存 |
| 两套入口协议漂移 | 根入口/快速入口的种子、配置、选轮次及标准差定义不同 | eval_5folds.py 直接使用同一训练入口 |
| 指标提前舍入/证据不足 | 指标函数先保留四位小数；只有汇总日志，没有预测或 checkpoint | 指标保留全精度，保存预测、权重、折 ID、配置、哈希和训练轨迹；独立核算 AP/Micro-F1 |

修复前回归测试实际为 1 通过、4 失败，覆盖 float64、无负样本、跨折参数污染、不同数据集缓存。普通 float32 组上，Gemini 向量化与旧循环的损失/梯度一致至浮点误差，因此不能把“速度快”本身当成作假证据。验证结果另见 `AUDIT_VALIDATION.json`。

## 不能靠本次修复解决的原方法来源问题

HEAD `1733ce0` 和本地 ZIP 的配置只有 Emotions；当前 Corel5k 深编码器 `[512,128]`、65 epoch、lr=0.003、weight_decay=0.003、阈值 0.30 等来源是本地适配与调参。没有核实到作者 Corel5k 完整配置。本地 ZIP 含后加中文注释，还残留一个旧 topk 返回值问题，不能当作未修改的作者源码盲目覆盖。

以下差异继承自原代码，本轮**未改变目标函数或消息传播定义**，以免悄悄创造另一种方法：

1. 论文式(8) `Q=σ(HᵀZ)` 是求和，代码输出超边为原节点特征的均值后激活。两节点超边的均值与求和相差两倍；可变超边大小下不能视为普遍恒等。
2. 论文式(9) 原型为原始 q 的平均，代码先逐行归一化再平均并归一化。向量长度不同时两者不等价。Gemini 向量化保留的是原代码行为。
3. 论文式(11) 写 BCE 求和，代码采用平均；这会影响与 alpha 的相对量级，不能擅自替换后继续声称同一作者配置。
4. `test_thr=99` 会过滤正常余弦相似度，因此评估时每个视图内仅自环；同一样本跨视图连接仍在。论文对无标签推理阶段的构图说明不足，不能自行把阈值调低当成修复。

严格论文复现仍需作者数据/配置/原始源码和推理规则的来源确认。这些差异不能通过把指标调到接近论文来消除。
