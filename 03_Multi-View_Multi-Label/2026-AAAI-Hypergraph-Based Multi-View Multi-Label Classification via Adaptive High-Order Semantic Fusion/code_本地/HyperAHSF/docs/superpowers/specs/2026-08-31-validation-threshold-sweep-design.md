# 验证超图余弦阈值诊断实验设计

## 目标

确认作者原始配置 `test_thr: 99` 导致验证集视图内超图只剩自环后，改用合法余弦阈值是否会稳定改变 Emotions 五折验证性能。实验只诊断验证构图敏感性，不把表现最好的阈值直接声明为修复值或正式测试结果。

## 已确认事实

- 本地原始 `HyperAHSF.zip` 的 `config.yaml` 已经写有 `test_thr: 99`，不是后续注释或消融改动造成的。
- 原始 `model.py` 直接比较 `neighbor_cos_sim < thr`，没有除以 100 或百分位转换。
- 余弦相似度范围为 `[-1, 1]`，因此阈值 99 会过滤全部视图内候选邻居。
- 验证局部图仍保留每个节点的自环；统一验证图仍保留同一样本不同视图之间的跨视图超边。
- `test_thr` 只影响验证/测试构图，不影响训练超图和模型参数更新。

## 实验变量

使用同一训练权重分别评估以下阈值：

| 名称 | `test_thr` | 含义 |
|---|---:|---|
| `author_99` | 99.0 | 作者原始配置，过滤全部验证近邻 |
| `cos_099` | 0.99 | 极严格特征余弦过滤 |
| `cos_095` | 0.95 | 严格特征余弦过滤 |
| `cos_090` | 0.90 | 较宽松特征余弦过滤 |
| `knn_all` | -1.0 | 保留全部 KNN 候选，不再由余弦阈值删除 |

除了 `test_thr`，所有数据划分、随机种子、模型参数、训练超图、优化器、损失、训练 epoch 和二值预测阈值均保持一致。

## 训练与评估数据流

每折只创建并训练一个基线模型。每个 epoch 完成一次全批量训练更新后，对五个阈值依次执行验证：

1. 清除 `model.test_hyperedge_index` 与 `model.eval_hyperedge_index`；
2. 设置当前验证阈值；
3. 仅从验证特征构造该阈值对应的视图内超图；
4. 构造包含跨视图超边的统一验证超图；
5. 在 `model.eval()` 和 `torch.no_grad()` 下预测；
6. 使用同一验证标签计算八项指标；
7. 保存该阈值的图结构统计和性能指标。

缓存必须按阈值隔离，禁止修改阈值后复用前一个阈值生成的验证图。不同阈值的评估不能更新模型参数、BatchNorm 统计或优化器状态。

## 实现边界

新增代码放在 `experiments/validation_threshold/`，不直接改写 `config.yaml` 中的作者原值 99，也不覆盖原始 `train.py`。实验运行器复用现有模型、数据读取和指标函数，通过明确的阈值参数控制验证图。

公共接口包括：

- 阈值配置列表与稳定名称；
- 清除验证图缓存并以指定阈值验证的函数；
- 统计每个视图自环、多节点超边、成员数和超边大小的函数；
- 单折冒烟与五折完整实验命令；
- CSV/JSON/SVG/Markdown 汇总输出。

## 测试要求

采用测试驱动实现，至少覆盖：

1. `99` 过滤所有非自环候选；
2. `-1.0` 保留全部 KNN 候选；
3. 切换阈值前会清空两类验证图缓存；
4. 多个阈值共享同一模型参数对象，验证前后参数完全不变；
5. 阈值顺序改变时，同一阈值的图统计和预测保持一致；
6. 输出行同时包含 `variant/fold/epoch/threshold` 与八项指标；
7. 现有 `experiments/hgnn_ablation` 和项目语法检查继续通过。

## 运行阶段

先运行 `fold0 × 20 epoch` 冒烟实验，检查数值、缓存隔离、图统计和输出格式。冒烟通过后运行 `5 folds × 125 epochs`。因为每折每个 epoch 训练一次、验证五次，训练成本不重复，但验证成本约增加到原来的五倍。

## 输出

所有生成结果写入未覆盖既有结果的独立目录：

```text
research_outputs/validation_threshold_sweep/
├── metrics.csv
├── graph_statistics.csv
├── aggregate_results.csv
├── config.json
├── learning_curves.svg
└── 验证阈值诊断报告.md
```

报告必须同时展示五个阈值，不得只保留最优阈值。至少汇总 AP、Micro-F1、Macro-F1、Hamming Loss、五折标准差、逐折胜负、非自环超边比例和运行时间。

## 结论边界

- 某个合法阈值优于 99，只能说明保留验证近邻在本次诊断中有利，不能证明作者原值是笔误。
- 99 优于其他阈值，支持“禁用验证局部近邻可能是稳健选择”，但仍不能证明作者设计意图。
- 固定阈值在两个视图产生明显不同的边密度时，应报告跨视图不可比问题，不在本实验中继续调每视图阈值。
- 由于多个阈值在同一验证折上比较，最优结果属于事后诊断，不能直接替换论文正式结果；正式选择需要嵌套验证或独立测试集。
