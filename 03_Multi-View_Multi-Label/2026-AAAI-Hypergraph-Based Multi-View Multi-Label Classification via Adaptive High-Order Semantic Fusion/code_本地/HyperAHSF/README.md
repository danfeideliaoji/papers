## 2. 论文与代码核对结果

论文式（1）描述的视图内超边构造过程为：

1. 在特征空间中为每个样本选择 KNN 候选邻居；
2. 使用真实标签的 Jaccard 相似度进一步筛选候选邻居；
3. 为每个样本额外添加一条自环超边。

训练阶段可以使用训练标签，因此代码能够执行上述标签筛选。验证或测试阶段没有可用的真实标签，论文正文没有明确说明此时如何替代标签筛选；当前代码改用特征余弦相似度构图。

Emotions 配置中：

- `test_k = 6`：除中心样本自身外，每个样本最多考察 6 个候选邻居；
- `test_thr = 99`：验证构图使用的余弦相似度阈值。

余弦相似度通常位于 `[-1, 1]`，因此阈值 99 会过滤所有非自环邻居。五折、两个视图的诊断均确认验证图只剩自环，即没有样本之间的传播；模型仍然可以依靠样本自身特征完成分类。

> 注意：论文没有给出验证阶段的余弦阈值，所以目前不能直接认定 99 是“代码与论文不一致”或作者笔误。更准确的记录是：论文对无标签评估阶段的构图规则说明不足，而公开代码采用 99，实际效果等价于不进行样本间传播。

## 3. 验证阈值诊断

诊断实验复用相同训练过程，只改变验证构图阈值。下表按每折 AP 最佳 epoch 汇总五折结果：

| 验证阈值 | 平均 AP | Micro-F1 | 图结构 |
|---:|---:|---:|---|
| 99 | 0.8470 | 0.6963 | 仅自环 |
| 0.99 | 0.8458 | 0.6951 | 少量非自环传播 |
| 0.95 | 0.8443 | 0.6972 | 增加非自环传播 |
| 0.90 | 0.8437 | 0.6955 | 进一步增加传播 |
| -1（保留全部 KNN） | 0.8260 | 0.6697 | 全部候选参与传播 |

当前证据只能说明：在 Emotions、当前模型和当前设置下，直接保留更多特征近邻没有带来稳定提升；保留全部 KNN 邻居时性能明显下降。不能仅凭该实验推断“99一定正确”，也不能直接归因于数据集规模较小。

## 4. 预测标签辅助构图：候选实验

为了减小训练与验证构图依据的差异，`experiments/candidate1/` 实现了一个由 GPT 辅助编写的初步验证版本。主要变化为：

1. 在每个视图的特征编码器后增加一个独立标签预测头；
2. 预测头使用训练标签和辅助 BCE 损失训练，损失权重为 0.2；
3. 辅助损失对编码表示停止梯度，尽量避免改变原主干；
4. 使用 EMA 教师输出较平滑的单视图标签概率；
5. 在特征 KNN 的 6 个候选内，结合特征距离、预测标签相似度和预测可靠度分配软传播权重；
6. 将原来的等权超图传播改为加权传播；
7. 训练和验证使用同一套预测概率辅助构图规则，验证真实标签不参与构图。

Candidate 1 前 10 个 epoch 只按特征构图；之后训练和验证均由预测概率辅助构图，不再使用原训练图中的真实标签 Jaccard 筛选。真实训练标签仅用于训练预测头和原有监督损失。

简化流程：

```text
单视图特征 -> 特征编码器 -> 标签预测头 -> 各标签预测概率
                                      |
特征 KNN 候选 + 预测概率相似度 + 可靠度
                                      |
                            加权超图传播 -> 最终分类
```

为与本地原始复现日志保持一致，下面报告预先固定的第 107 epoch，而不是从验证结果中挑选最佳 epoch：

| 方法 | AP | Micro-F1 |
|---|---:|---:|
| 原 HyperAHSF | 0.8420 | 0.7030 |
| Candidate 1 | 0.8156 | 0.6844 |

Candidate 1 的 AP 下降 0.0264，Micro-F1 下降 0.0186。原始 KNN 的零标签重叠关联率为 37.5%，Candidate 1 为 36.8%，只相对下降约 1.9%。当前实现没有达到预期，不应作为已经成立的创新点。由于本表使用固定第 107 epoch，而上一节阈值表按每折最佳 AP epoch 汇总，两张表的“原方法”数字不能直接横向比较。

当前公式存在一个明确的结构性限制：softmax 会给每个候选邻居非零权重，因此该版本只能调整邻居权重，不能真正拒绝错误邻居。这是结果不理想的可能原因之一，但现有实验还不能证明它是唯一原因。这个实验否定的是当前具体公式，并没有完全否定“预测语义辅助可靠构图”这一研究问题。

详细结果见：`research_outputs/candidate1/Candidate 1 实验报告.md`。

## 5. 标签使用与实验边界

- 训练标签可以用于训练损失、训练构图和预测头监督；
- 验证或测试真实标签不能作为模型输入，也不能参与构图；
- 验证或测试标签只用于预测完成后的指标计算和离线图质量诊断；
- `oracle` 使用真实标签构图，只用于估计结构上限，不能作为可部署方法或正式对比结果；
- 阈值扫描使用了留出折比较多个设置，因此属于诊断/调参证据，不应包装成独立测试集上的最终结论。
