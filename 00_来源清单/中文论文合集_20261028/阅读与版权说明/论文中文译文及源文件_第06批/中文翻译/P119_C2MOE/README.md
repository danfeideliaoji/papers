# P119 C²MOE 中文全文翻译

主文件：`P119_C2MOE_中文全文译文.pdf`，22 页。

完整覆盖已核验的 10 页 arXiv v1 原稿：标题、作者与机构、摘要、CCS 概念、关键词、ACM 模板参考格式，正文第 1-7 节及全部小节，26 个陈列公式（25 个带原稿编号，1 个未编号高斯分布式），全部行内公式，5 幅图、3 张表与 63 条参考文献。不是摘要替代全文。图表及复杂数学符号经逐项核对。

## 文件

- `translation.zh.md`：完整可编辑中文译稿，含 LaTeX 公式与原图占位引用。
- `build.json`：原稿 SHA-256、输出名，以及 8 个图表原图裁剪的源页码与坐标。
- `assets/`：原 PDF 按 3 倍比例渲染的 5 幅图和 3 张表。表 1、表 2 保留全部列与数值，拆成上下两组，并重复左侧索引列以便放大阅读。
- `source/arxiv-2608.04013v1.pdf`：核验过的原稿，未修改。
- `source-verification.json`：原始来源、许可与初始异常核验记录。
- `references.json`：63 条原文参考文献信息与对应中文题名。
- `LICENSE.md`：署名、来源、许可和翻译/重排变更说明。
- `QA.md`：逐页与逐资产可视检查、正文覆盖及原稿异常记录。
- `qa/`：22 页最终 PDF 的渲染图、PDF 抽取文本与结构检查报告。
- `build_report.json`：构建和最终 QA 状态。
- `SHA256SUMS.txt`：核心文件与图表资产的 SHA-256。

## 重建

从 `papers-cloud` 根目录执行：

```sh
PYTHONPATH=/tmp/cloud-pdf-deps python 中文翻译/scripts/build_cloud.py 中文翻译/P119_C2MOE/build.json
```

依赖：PyMuPDF、Pillow、pandoc、Noto Serif CJK SC / Noto Sans CJK SC / Noto Serif 字体、WeasyPrint 70.0、ziamath 0.13。构建器先验证源文件哈希，再生成原图裁剪、MathML/SVG 公式与 PDF。版式调整已写入 Markdown；未修改共享渲染器。重新构建会把可视 QA 状态重置为 pending，应重新渲染检查后再交付。

## 忠实性与已知原稿问题

- arXiv 标识符 `2608.04013v1` 与官方页面/PDF 的日期 `22 Apr 2026` 不一致；两者均保留，不推定修正日期。
- 原稿 ACM 模板中有 `2018`、`Conference’17, July 2017, Washington, DC, USA` 和占位 DOI。译文明确它们不是已核验的正式发表信息。
- 式 (10)、(12)、(14)、(15) 重复编号，式 (13) 位于 (15) 后；全部照原稿顺序保留。
- 式 (8) 后的“第 K 位专家”、式 (16) 的 `P^p` 与 `P^comp` 差异、式 (17) 的负期望重建误差，以及式 (21) 两处 `+·` 均保留。
- 缺失率上界在三模态时为 2/3，但原稿同时给出 0.7 实验；不补造采样解释。
- 第 6.3 节损失记号和“仅使用”描述与表 3 勾选项存在不一致；保留并注释。
- 第 6.4 节的 `Fig. ??` 按原稿保留为“图 ??”，不偷偷替换引用。
- 表 2 原有重复值和与表 1 不一致的数值均保留；参考文献 [53]、[54] 的相似题名及不同年份均保留。

原图英文标签配有中文释义，文献保留英文检索信息并提供中文题名。拉丁变音作者姓名使用 Noto Serif，以避免 CJK 字体回退造成重音字母错误。
