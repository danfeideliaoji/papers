# P173 中文全文译文

- `P173_Tensorized_中文全文译文.pdf`：中文全文阅读版。
- `translation.zh.md`：可编辑中文全文（含全部正文、算法、证明、附录以及41条原文参考文献）。
- `build.json`：源文件哈希、裁剪坐标、输出配置。
- `assets/`：原始图表及复杂证明公式的300%比例裁剪；图题/解释用中文重排。
- `source/LICENSE_REVIEW.md`：来源、许可、逐图检查与图1第三方素材限制。
- `source/source-extracted.txt`：15页英文源文的文本提取，用于核对。
- `source/references.txt`：原文参考文献独立文本。
- `qa/`：最终PDF逐页PNG与联络表。
- `qa_report.json` / `review.md`：核验记录。

范围：标题、作者/机构、摘要、正文1–6节、算法1、影响声明、致谢、41条参考文献、附录A完整证明、附录B完整实验；保留7幅图、5张表、29个编号公式和附录无编号公式。不是摘要版。表2拆为两段以保留全部数值；表1/3可编辑，表2/4/5使用原图。编号公式22、24–29使用原图保证符号与原文一致，其余公式为可编辑LaTeX。
